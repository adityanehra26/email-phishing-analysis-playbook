# Email Phishing Analysis Playbook

This repository documents a **practical, analyst-driven approach to phishing email analysis**, based on real-world SOC investigations.

The focus of this project is **analysis and investigation**, not incident governance or response planning.  
Incident Response Plans for phishing are maintained separately in a dedicated IR repository.

---

## Purpose

This playbook is intended to:
- Document how phishing emails are analyzed in a SOC
- Provide a structured investigation methodology
- Demonstrate evidence-driven decision making
- Serve as a reference for analysts during investigations

---

## Scope

This repository covers:
- Phishing email analysis methodology
- Header analysis
- URL and attachment analysis
- Documentation practices
- Sanitized real-world case studies

It does **not** cover:
- Incident response governance
- Containment or recovery procedures
- Organizational policy enforcement

---

## Repository Structure

- `methodology.md` – Step-by-step phishing analysis workflow
- `real-world-case-study.md` – Sanitized phishing investigation example
- `header-analysis.md` – Email header analysis techniques
- `url-analysis.md` – URL inspection and sandboxing
- `attachment-analysis.md` – Static and dynamic attachment analysis
- `documentation-template.md` – Investigation documentation template

---

## Disclaimer

All examples, indicators, and artifacts are **sanitized and modified** to remove sensitive or identifying information.  
This repository is intended for educational and portfolio demonstration purposes.
