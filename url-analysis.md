# URL Analysis in Phishing Emails

URLs are commonly used to deliver phishing payloads or harvest credentials.


## URL Extraction

- Extract URLs from email body
- Decode encoded or shortened URLs
- Identify subdomain abuse or typosquatting


## Analysis Steps

- Domain age and registration details
- Reputation checks
- Hosting infrastructure analysis
- Dynamic sandbox execution


## Common Red Flags

- Newly registered domains
- Free hosting providers
- Mismatch between link text and actual URL
- Use of URL shorteners


## Tools Commonly Used

- urlscan.io
- VirusTotal
- PhishTank
- Netcraft
