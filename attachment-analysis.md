# Attachment Analysis in Phishing Emails

Attachments are used to deliver malware or initiate further compromise.


## Initial Handling

- Extract attachment safely
- Calculate file hashes
- Identify file type


## Static Analysis

- Metadata inspection
- Embedded objects
- Macro detection
- Script extraction


## Dynamic Analysis

- Execute in isolated sandbox
- Monitor process activity
- Observe network connections
- Capture dropped files


## Common Attachment Types

- Office documents with macros
- PDFs with embedded scripts
- Archives containing executables
